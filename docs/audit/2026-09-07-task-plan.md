## Decisions Made
| Decision | Rationale |
|----------|-----------|
| 以服务端鉴权作为安全边界，前端仅作状态展示 | 只隐藏 UI 不能防止匿名接口读取数据 |
| 私人作品、图片、额度、生成和购买接口统一要求非游客账户 | 防止任何旧游客 token 继续访问或消费账户资源 |
| 公共 discover/products/auth config 保持匿名可访问 | 未登录用户仍能浏览风格并注册 |
| 网页启动不再静默创建游客账号 | 避免匿名 token 与本地“已登录”标记漂移 |
